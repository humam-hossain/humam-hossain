## Phase Boundary

Deliver a terminal-styled metrics section in `README.md` (between `<!-- METRICS:START -->` and `<!-- METRICS:END -->`) and a retro visitor counter in the top badges row. The section features:
1. A unified dark terminal SVG window (`assets/metrics.svg`, viewBox 850px) displaying commit streak stats and contribution totals on the left panel, and top languages horizontal progress tracks on the right panel.

<decisions>
## Implementation Decisions

### Metrics Card Architecture & SVG Window
- **D-01:** **Unified Terminal SVG Window (`assets/metrics.svg`)** — Single self-contained 850px-wide SVG terminal window generated by `scripts/generate_metrics.py` using design tokens from `config/terminal_theme.json`. Matches `assets/hero.svg` and `assets/projects.svg` in geometry, corner radius (`rx="10"`), border (`#30363d`), header bar (`#161b22`), and console body (`#0d1117`). — **Reversibility:** costly — Generator architecture and test suites depend on this unified SVG asset.
- **D-02:** **Window Chrome & Prompt** — Title bar `stats — zsh` with colored traffic lights (🔴 `#ff5f56`, 🟡 `#ffbd2e`, 🟢 `#27c93f`) and terminal prompt line: `humam@workstation:~$ git status --telemetry`.
- **D-03:** **Two-Column Split Layout** — Left panel (~42% width) for Streak & Contribution Telemetry; Right panel (~58% width) for Top Languages breakdown with horizontal progress tracks.
- **D-04:** **Streak & Contribution Metric Cards (Left Panel)** — 3 stacked mini-panels (`#161b22` background, `#30363d` 1px border, rounded `rx="6"`):
  - Amber `⚡ Current Streak` with bold 20px numbers (`#ffa657`)
  - Blue `★ Longest Streak` with bold 20px numbers (`#58a6ff`)
  - Green `◆ Total Contributions` with bold 20px numbers (`#3fb950`)
- **D-05:** **Streak Calculation Logic** — GitHub-standard calendar days with today-grace-period (if user pushed yesterday, the streak remains active giving until end-of-day UTC to push today). Consecutive days including weekends.
- **D-06:** **Contribution Scope & Inactive Handling** — Counts full GitHub contribution calendar events (commits, PRs, issues, reviews). When current streak is 0, display `0 days` with muted gray badge `[standby]` (`#8b949e`), preserving layout symmetry.

### Top Languages Telemetry & Progress Bars (Right Panel)
- **D-07:** **Vector SVG Progress Tracks (Cross-Platform Stability)** — Progress bars rendered as clean vector `<rect>` tracks (background track `#21262d`, filled track with language color) inside the SVG. This eliminates cross-platform Unicode font advance width discrepancies across macOS, Windows, Linux, and iOS while maintaining crisp terminal alignment. — **Reversibility:** costly
- **D-08:** **Language Weighting & Scope** — Sourced from repository byte counts across all owned public non-fork repositories via GraphQL `languages` field, accurately reflecting code volume.
- **D-09:** **Language Capacity** — Top 5 highest-byte languages + an aggregated "Other" catch-all row (if remaining languages exceed 1%), aligning vertically with the 3 left-panel streak cards.
- **D-10:** **Language Colors** — Official GitHub Linguist colors fetched via GraphQL with fallbacks to `config/terminal_theme.json` ANSI tokens for custom/unrecognized extensions.
- **D-11:** **Column Alignment** — 12-character fixed-width left-aligned language name column with a colored indicator dot (e.g. `● Python      [████████░░] 64.2%`), keeping all progress tracks and percentage readouts on consistent vertical baselines.
- **D-12:** **Prose / Documentation Filtering** — Configurable ignore list in `config/terminal_theme.json` (defaulting to `["HTML", "CSS", "TeX", "Markdown"]`) so primary programming languages (Python, Bash, C++, JavaScript) are prioritized.

### Recent Git Activity Stream (`README.md`)
- **D-13:** **Markdown `<pre><code>` HTML Container** — Rendered in `README.md` between `<!-- METRICS:START -->` and `<!-- METRICS:END -->` as an authentic terminal code block with prompt `humam@workstation:~$ git log --graph --oneline -n 6`.
- **D-14:** **Clickable Terminal Links** — By using `<pre><code>` in HTML, commit hashes (`[a1b2c3d]`) and repository tags (`(repo-name)`) are live clickable `<a href="...">` hyperlinks to GitHub commit and repo pages.
- **D-15:** **Event Depth & Layout** — Exactly 5 to 6 recent events displayed to ensure a compact, informative stream without excessive vertical scrolling.
- **D-16:** **Line Structure** — `* [a1b2c3d] (repo-name) Commit summary message (X days ago)` with git graph asterisk `*`, relative time, and 1-line summary clamped to 50 characters with ellipsis (`...`).
- **D-17:** **Activity Feed Source** — Public activity feed via GitHub Public Events (`/users/{username}/events/public`) or GraphQL commits, capturing commits and merged PRs across all public repositories.
- **D-18:** **Automated Bot Filtering** — Automated commits from `github-actions[bot]`, `dependabot[bot]`, and profile updater commits (`docs(update): ...`) are filtered out to display only genuine engineering work.

### Retro Visitor Counter Badge
- **D-19:** **Flat-Square Terminal Badge** — Matches the existing top contact badge row directly below `assets/hero.svg`: `#161b22` background, Amber label `session_hits`, terminal logo (`logo=gnometerminal&logoColor=ffa657`), and Green counter digits (`#3fb950`).
- **D-20:** **Zero-Maintenance Counter Service** — Powered by `komarev.com` (or `hits.seeyoufarm.com`) parameterized via standard query URL: `https://komarev.com/ghpvc/?username=humam-hossain&color=3fb950&labelColor=161b22&style=flat-square&label=session_hits`. Real-time counting on GitHub Camo proxy with zero Python API calls or cron maintenance.
- **D-21:** **Badge Placement** — Appended as a 5th badge directly in the top contact badges row beneath the Hero card.

### Engine, Cache & Offline Test Resilience
- **D-22:** **Consolidated GraphQL & REST in Python** — `scripts/update_profile.py` queries `contributionsCollection.contributionCalendar` alongside repository languages in existing queries; queries public events with rate-limit handling.
- **D-23:** **Incremental Telemetry Caching** — Streak stats, language byte totals, and recent activity are cached in `data/cache.json` under `streak_metrics`, `top_languages`, and `recent_activity`.
- **D-24:** **Standalone Generator (`scripts/generate_metrics.py`)** — Dedicated generator script handling SVG XML rendering and ElementTree validation, callable by `update_profile.py` or directly via CLI.
- **D-25:** **100% Offline Pytest Suite (`tests/test_metrics.py`)** — Fixture data in `tests/fixtures/` and cache fallback ensure that all SVG generation and README injection tests pass with zero network access and without tokens.

### the agent's Discretion

- Relative time formatting math in Python (e.g. `2 hours ago`, `3 days ago`, `2 weeks ago`).
- SVG gradient or flat fill styling for the vector progress tracks.
