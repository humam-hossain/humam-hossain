# Plan 04-01: Metrics Test Fixtures & Top Languages Telemetry Engine

## Executive Summary

Establish the telemetry test harness, offline JSON fixtures, and language aggregation engine for Phase 4 as a tracer slice. Plan 04-01 creates mock response fixtures (`graphql_calendar.json`, `graphql_languages.json`, `rest_events.json`) in `tests/fixtures/` and seeds `tests/test_metrics.py` to enforce strict offline testability under complete network isolation per D-25. It extends `config/terminal_theme.json` with a configurable language ignore list (`HTML`, `CSS`, `TeX`, `Markdown`) per D-12 to filter documentation and markup prose. It builds `aggregate_top_languages()` and `fetch_language_telemetry()` in `scripts/update_profile.py` with multi-tier fallback (Live GraphQL -> Cache -> Fixtures) per D-08, D-09, D-10, and D-22, computing exact byte percentages for top 5 programming languages plus an aggregated "Other" catch-all row.

## Threat Model (ASVS Level 1)

<threat_model>
### STRIDE Threat Register

| Threat ID | Category | Component | Description | Mitigation Strategy |
|-----------|----------|-----------|-------------|---------------------|
| T-04-01 | Tampering | `scripts/update_profile.py:aggregate_top_languages` | Malformed API JSON or missing repository nodes in GraphQL response causing unhandled `KeyError` or `TypeError`. | Use defensive `.get()` navigation on `repo.get("languages", {}).get("edges", [])` and validate node types before parsing byte sizes. |
| T-04-02 | Denial of Service | `scripts/update_profile.py:aggregate_top_languages` | Account with zero valid language bytes or empty repositories causing `ZeroDivisionError` during percentage calculation. | Guard percentage calculation with `(bytes / total_bytes * 100.0) if total_bytes > 0 else 0.0`. |
| T-04-03 | Injection | `scripts/update_profile.py:fetch_language_telemetry` | Injection of untrusted language names or color strings containing XML/HTML tags into downstream renderers. | Ensure `aggregate_top_languages()` validates and clamps language names, passing clean data structures to downstream escaping filters. |
| T-04-04 | Information Disclosure | `scripts/update_profile.py:fetch_language_telemetry` | Leaking `GITHUB_TOKEN` in console log output or exception messages during query failures. | Catch exceptions generically in telemetry fetchers, log warnings with `log_warn()`, and omit request headers from log output. |
</threat_model>

### Task 04-01-02: Configure Language Filtering & Implement Language Telemetry Engine (`config/terminal_theme.json`, `scripts/update_profile.py`, `tests/test_metrics.py`)

<read_first>
- config/terminal_theme.json (Existing telemetry section)
- scripts/update_profile.py (GraphQL execution patterns and cache helpers)
- .planning/phases/04-languages-streaks-metrics/04-RESEARCH.md (Section 7.2)
- .planning/phases/04-languages-streaks-metrics/04-PATTERNS.md (Section 2.1, Section 3.2)
</read_first>

<action>
1. In `config/terminal_theme.json`, extend the `"telemetry"` section to add `"ignore_languages": ["HTML", "CSS", "TeX", "Markdown"]` per D-12, keeping existing keys `"exclude_repos"` and `"baseline_override_date"` intact.
2. In `scripts/update_profile.py`, define `DEFAULT_LANGUAGE_FIXTURES` with a list of dictionaries for Python (65000 bytes, color `#3572A5`, 52.0%), Shell (42000 bytes, color `#89e051`, 33.6%), and C (18000 bytes, color `#555555`, 14.4%).
3. Implement `aggregate_top_languages(repo_nodes: list[dict], ignore_list: list[str] | None = None) -> list[dict]` in `scripts/update_profile.py` per D-08, D-09, D-10, D-12:
   - Skips repos where `repo.get("isFork")` is `True` per D-08.
   - Extracts language edges from `repo.get("languages", {}).get("edges", [])`.
   - Filters out language names present in `set(ignore_list or ["HTML", "CSS", "TeX", "Markdown"])`.
   - Aggregates byte counts into `lang_bytes: dict[str, int]` and saves color in `lang_colors: dict[str, str]`.
   - If `total_bytes == 0`, returns empty list `[]` (prevents division by zero per T-04-02).
   - Sorts languages descending by byte count; selects top 5 languages.
   - If remainder languages exist and their byte share represents >= 1.0% of total bytes, appends an aggregated `"Other"` entry with color `"#8b949e"` and rounded percentage per D-09.
   - Returns list of dicts with keys: `name` (str), `bytes` (int), `color` (str), `percentage` (float rounded to 1 decimal place).
4. Implement `fetch_language_telemetry(config: dict, cache: dict, token: str | None = None) -> list[dict]` in `scripts/update_profile.py` per D-22:
   - Tier 1: If `token` is present, executes GraphQL query for `viewer.repositories(first: 100, isFork: false) { nodes { name isFork languages(first: 10, orderBy: {field: SIZE, direction: DESC}) { edges { size node { name color } } } } }`, aggregates languages using `config.get("telemetry", {}).get("ignore_languages")`, updates `cache["top_languages"]`, and returns results.
   - Tier 2: If query fails or no token, checks `cache.get("top_languages", {}).get("languages")`; if present, returns cached list.
   - Tier 3: Falls back to `DEFAULT_LANGUAGE_FIXTURES`, logging `log_warn()`.
5. In `tests/test_metrics.py`, import `aggregate_top_languages`, `fetch_language_telemetry`, and `DEFAULT_LANGUAGE_FIXTURES`, and add unit tests:
   - `test_language_aggregation_percentages`: validates percentages sum to ~100% on fixture data.
   - `test_language_ignore_list_filtering`: verifies Markdown, HTML, and CSS are excluded from totals.
   - `test_language_other_row_roll_up`: verifies remaining languages beyond top 5 rolling up into "Other" when >= 1%.
   - `test_language_zero_bytes_safety`: verifies empty node list returns `[]` without `ZeroDivisionError`.
   - `test_fetch_language_telemetry_cache_fallback`: verifies offline fallback returns cached data or default fixtures.
</action>
