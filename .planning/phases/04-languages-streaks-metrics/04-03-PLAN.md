# Plan 04-03: Retro Terminal Visitor Counter Badge

## Executive Summary

Integrate a zero-maintenance retro terminal session hits visitor counter badge into the profile's top contact row per METRIC-03. Plan 04-03 implements `update_readme_badges()` in `scripts/update_profile.py` using the standard Komarev profile views counter service (`komarev.com/ghpvc`) styled as a terminal badge with dark background (`#161b22`), Green counter digits (`#3fb950`), flat-square geometry, and label `session_hits` per D-19 and D-20. It places the badge as the 5th badge in the top contact row directly below `assets/hero.svg` and adjacent to the Resume badge per D-21. Strict idempotency checking guarantees that subsequent updater invocations make zero redundant disk writes. Tests in `tests/test_metrics.py` assert URL formatting, correct DOM placement, and idempotent execution.

<action>
1. In `scripts/update_profile.py`, define `VISITOR_BADGE_MARKDOWN` as `[![session_hits](https://komarev.com/ghpvc/?username=humam-hossain&color=3fb950&labelColor=161b22&style=flat-square&label=session_hits)](https://github.com/humam-hossain)`.
2. Implement `update_readme_badges(readme_path: Path) -> bool` in `scripts/update_profile.py` per D-19, D-20, D-21:
   - Verifies `readme_path.is_file()`; returns `False` if missing.
   - Reads content from `readme_path`.
   - If `"session_hits"` is already in content, logs `log_info("README.md visitor badge already present (idempotent skip)")` and returns `False` per D-21.
   - Locates `"[![Resume]"` in content.
   - Finds the closing parenthesis `")"` of the Resume badge markdown link.
   - Inserts newline and `VISITOR_BADGE_MARKDOWN` immediately after that closing parenthesis.
   - Writes `new_content` to `readme_path` and logs `log_ok("Appended visitor counter badge to README.md")`.
   - Returns `True`.

   - `test_update_readme_badges_insertion`: uses `tmp_path` fixture with mock README containing Resume badge, verifies `update_readme_badges()` returns `True`, and checks resulting content has 5 badges in order.
   - `test_update_readme_badges_idempotence`: calls `update_readme_badges()` a second time on the same `tmp_path` README, verifying it returns `False` and leaves content byte-identical.
