# Plan 05-01: Terminal Skills Matrix SVG & Taxonomy Engine

## Executive Summary

Establish the categorized skills matrix for Muhammed Humam Hossain's GitHub Profile README as a tracer slice fulfilling requirement CONTENT-02. Plan 05-01 creates `config/skills.json` seeded directly from Humam's authentic resume inventory (`cv/sections/skills.tex`), defining 4 core disciplines (AI & Data Science, Backend & Systems, SQA & Automation, Embedded & Robotics) with ANSI theme accents. It builds `scripts/generate_skills.py` as a standalone CLI generator producing `assets/skills.svg` (850x380px) matching the design system of `assets/hero.svg`, `assets/projects.svg`, and `assets/metrics.svg` with window chrome, macOS traffic lights, and Neofetch prompt header (`neofetch --skills`). It implements a dynamic flow-pack algorithm with hard capacity capping (6 skills per quadrant) that arranges pills into exactly 2 rows with accent indicator dots and desktop CSS hover transitions. Finally, it integrates skills generation and idempotent README injection into `scripts/update_profile.py` and provides a comprehensive offline unit test suite in `tests/test_skills.py`.

## Threat Model (ASVS Level 1)

<threat_model>
### STRIDE Threat Register

| Threat ID | Category | Component | Description | Mitigation Strategy |
|-----------|----------|-----------|-------------|---------------------|
| T-05-01 | Tampering | `scripts/generate_skills.py:load_skills_config` | Corrupted or missing `config/skills.json` leading to unhandled `JSONDecodeError` or `FileNotFoundError` halting profile update pipeline. | Wrap file loading in defensive `try/except`, log warning via `log_warn()`, and fall back to built-in `DEFAULT_SKILLS_DATA` per D-11. |
| T-05-02 | Injection | `scripts/generate_skills.py:generate_skills_svg` | Untrusted or malformed skill strings containing `<script>`, `&`, `<`, `>`, or `"` causing XML syntax corruption or SVG breakout. | Strictly escape every category title and skill name with `xml.sax.saxutils.escape()`, and validate generated SVG using `xml.etree.ElementTree.fromstring()` before disk write per D-12. |
| T-05-03 | Denial of Service | `scripts/generate_skills.py:generate_skills_svg` | Oversized skill list or very long skill labels overflowing quadrant panel borders or colliding with adjacent quadrant text. | Enforce hard capacity capping at 6 skills per quadrant (`[:6]`) per D-08, and use monospace flow-pack width calculation (`32 + len(skill) * 6.8`) with line wrapping when `cur_x + pill_w > max_x`. |
</threat_model>
