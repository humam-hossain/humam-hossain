# Plan 03-02: Terminal Projects SVG Generator & Visual Contract

## Executive Summary

Build the standalone vector graphics generator (`scripts/generate_projects.py`) for the Open Source Projects Dashboard, delivering the visual design contract defined in `03-UI-SPEC.md` and user decisions D-01 through D-15. Plan 03-02 constructs an authentic Unix terminal window (`viewBox="0 0 850 340"`) featuring workstation header chrome, macOS traffic lights, Neofetch prompt line `humam@workstation:~/projects$ gh repo list`, and a 2x2 grid of project sub-panels (`#161b22`, `380x115px`). It implements entity-safe 2-line plain-text word wrapping with ellipsis truncation per D-13, font-independent inline Octicon vector paths, and ANSI syntax metric counters with muted zero counts (`#616e7f`) per D-11 and D-12. All SVG generation is strictly validated using `xml.etree.ElementTree` prior to disk writing. Extended tests in `tests/test_projects.py` guarantee XML well-formedness, exact geometry coordinates, and design token fidelity.

## Threat Model (ASVS Level 1)

<threat_model>
### STRIDE Threat Register

| Threat ID | Category | Component | Description | Mitigation Strategy |
|-----------|----------|-----------|-------------|---------------------|
| T-03-06 | Injection / XSS | `scripts/generate_projects.py:generate_projects_svg` | Stored XSS or XML injection via malicious strings in repository names, descriptions, or topic tags (e.g. `<script>`, `]]>`, unescaped `&`, `<`, `>`). | Strictly escape all dynamically interpolated text using `xml.sax.saxutils.escape()` after word-wrapping. Enforce strict DOM parsing with `xml.etree.ElementTree.fromstring()` before file writing per D-15. |
| T-03-07 | Denial of Service / Crash | `scripts/generate_projects.py:wrap_and_clamp_description` | `ElementTree.ParseError` caused by slicing strings containing XML entities (e.g., truncating `&amp;` to `&a...`). | Perform word wrapping and truncation on raw unicode text first; apply `saxutils.escape()` as the final step before SVG XML interpolation. |
| T-03-08 | Repudiation / Inconsistent Rendering | `assets/projects.svg` | Glyphs like `⑂` or `⌥` rendering as missing character tofu boxes (`□`) across mobile or Linux client browsers via Camo CDN. | Use normalized inline SVG `<path>` elements (GitHub Octicons 16x16) rather than OS monospace Unicode symbol glyphs. |
| T-03-09 | Tampering / Layout Defect | `scripts/generate_projects.py` | Long repo titles or descriptions overflowing sub-panel bounds, corrupting the 2x2 grid layout. | Constrain sub-panel width to 380px; clamp descriptions to 2 lines (~42 chars line 1, ~40 chars line 2) with ellipsis (`...`); truncate titles exceeding 28 characters. |
| T-03-10 | Supply Chain (SC) | `scripts/generate_projects.py` | Dependency vulnerabilities from third-party graphics libraries (e.g., Cairo, Pillow). | Pure Python standard library implementation (`xml.etree.ElementTree`, `xml.sax.saxutils`, `json`, `pathlib`). |
</threat_model>
