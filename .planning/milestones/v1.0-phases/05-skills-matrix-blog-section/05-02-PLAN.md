# Plan 05-02: Plug-and-Play Blog & Publications Terminal Section

## Executive Summary

Implement the plug-and-play blog and publications section for Muhammed Humam Hossain's GitHub Profile README fulfilling requirement CONTENT-01. Plan 05-02 establishes `config/articles.json` supporting both remote RSS 2.0 / Atom 1.0 feeds (`rss_url`) and curated articles seeded from Humam's robotics and embedded testing engineering projects. It provides offline XML fixtures (`feed_rss2.xml`, `feed_atom.xml`) and builds a resilient standard-library feed parser in `scripts/update_profile.py` that strips XML namespaces, normalizes RFC 822 and ISO 8601 dates to `YYYY-MM-DD`, sanitizes URLs against protocol breakout, and clamps titles to 55 characters for strict 80-column monospace terminal alignment. It adds a 12-hour TTL cache in `data/cache.json` with a multi-layer fallback cascade (Live Feed -> Cache -> Curated Articles -> Standby Message) guaranteeing zero CI build failures during network outages. Finally, it implements idempotent README injection between `<!-- BLOG:START -->` and `<!-- BLOG:END -->` as an authentic terminal log box (`cat ~/articles.log`) positioned directly below Skills, accompanied by a comprehensive offline test suite in `tests/test_blog.py`.

## Threat Model (ASVS Level 1)

<threat_model>
### STRIDE Threat Register

| Threat ID | Category | Component | Description | Mitigation Strategy |
|-----------|----------|-----------|-------------|---------------------|
| T-05-04 | Denial of Service | `scripts/update_profile.py:fetch_articles` | Slow, hanging, or giant remote RSS/Atom feed causing GitHub Actions runner timeout or memory exhaustion. | Enforce explicit 5-second socket timeout (`urllib.request.urlopen(req, timeout=5)`), clamp read buffer to 1MB (`resp.read(1024 * 1024)`), and catch all network exceptions (`URLError`, `HTTPError`, `TimeoutError`) to trigger fallback cascade per D-15. |
| T-05-05 | Injection | `scripts/update_profile.py:format_articles_terminal_log` | Untrusted feed titles containing malicious HTML tags (`<script>`) or dangerous URL protocols (`javascript:`) causing XSS or README layout breakout. | Strip all HTML tags using regex (`re.sub(r'<[^>]+>', '', title)`), unescape entities with `html.unescape()`, clamp length to 55 characters, re-escape with `html.escape()`, and validate URL scheme (allow only `http://` or `https://`, defaulting unsafe schemes to `#`). |
| T-05-06 | Tampering | `scripts/update_profile.py:fetch_articles` | Corrupted `data/cache.json` or malformed timestamp string crashing cache TTL evaluation. | Wrap cache reading and timestamp parsing in defensive `try/except` block, falling back to curated articles on any validation error without raising unhandled exceptions per D-18. |
</threat_model>

### Task 05-02-02: Implement Dual-Format Feed Parser, Date Normalizer, 12h Cache Engine, and Secure Terminal Log Formatter (`scripts/update_profile.py`, `tests/test_blog.py`)

- `normalize_date_string()` normalizes RFC 822/2822, ISO 8601, and plain `YYYY-MM-DD` date strings to `YYYY-MM-DD`.
- `fetch_articles()` implements 12-hour TTL cache check, 5-second socket timeout, 1MB buffer clamp, and cascading fallback (Live Feed -> Cache -> Curated Articles -> []).
- `format_articles_terminal_log()` outputs `<pre><code>` block with prompt `cat ~/articles.log`, clamps titles to 55 characters, unescapes/escapes HTML entities, and sanitizes unsafe URL protocols (`javascript:` to `#`).
- `tests/test_blog.py` passes all unit tests for RSS 2.0 parsing, Atom 1.0 parsing, date normalization, title clamping, URL sanitization, cache TTL hit/miss, network error fallbacks, and standby message.
</acceptance_criteria>

<action>
1. In `scripts/update_profile.py`, implement the blog/article engine:
   - Define path constant `ARTICLES_CONFIG_PATH = ROOT_DIR / "config" / "articles.json"`.
   - Implement `load_articles_config(config_path: Path) -> dict`: loads JSON with default fallback dictionary (`{"rss_url": "", "max_display": 4, "curated_articles": []}`).
   - Implement `normalize_date_string(date_str: str) -> str`:
     - Checks if string is already `YYYY-MM-DD` (length 10, hyphens at index 4 and 7).
     - Tries `datetime.datetime.fromisoformat(date_str.replace("Z", "+00:00"))`.
     - Tries `email.utils.parsedate_to_datetime(date_str)`.
     - Falls back to `datetime.date.today().strftime("%Y-%m-%d")`.
   - Implement `parse_feed_xml(xml_bytes: bytes) -> list[dict]`:
     - Parses XML root using `ET.fromstring(xml_bytes)`.
     - Extracts local root tag via `root.tag.split("}")[-1].lower()`.
     - If `rss`: extracts channel title as default platform, loops over `.//item`, extracts `title`, `link`, `pubDate`, normalizes date, and appends to results.
     - If `feed`: extracts feed title as default platform, loops over `entry` elements (checking `elem.tag.split("}")[-1].lower() == "entry"`), extracts `title`, `link` (`elem.attrib.get("href") or elem.text`), and `published`/`updated` date, normalizes date, and appends to results.
     - Returns list of article dicts: `[{"title": ..., "url": ..., "date": ..., "platform": ...}]`.
   - Implement `fetch_articles(articles_config: dict, cache: dict, force_refresh: bool = False) -> list[dict]`:
     - Checks `cache.get("articles")`: if `last_updated` exists and elapsed time since `last_updated` is < 12 hours (and not `force_refresh`), returns cached `items`.
     - If `rss_url` is configured: sends HTTP GET request with `headers={"User-Agent": "humam-hossain-profile-updater"}`, `timeout=5`.
     - Reads up to `1024 * 1024` bytes (1MB clamp per T-05-04).
     - Calls `parse_feed_xml()`; on success, updates `cache["articles"]` with `last_updated` UTC timestamp and returns parsed items.
     - On any `URLError`, `HTTPError`, `TimeoutError`, or XML parse error: logs warning via `log_warn()`, falls back to existing cached items if available, then to `articles_config.get("curated_articles", [])`.
     - If all article sources are empty, returns `[]`.
   - Implement `format_articles_terminal_log(articles: list[dict], max_display: int = 4) -> str`:
     - Opens `<div align="left">\n<pre><code>humam@workstation:~$ cat ~/articles.log`.
     - If `articles` is empty: appends `* [standby] feed listener active — configure rss_url in config/articles.json`.
     - Else: for each article up to `max_display`:
       - Strips raw HTML tags from title: `clean_title = re.sub(r"<[^>]+>", "", art.get("title", ""))`.
       - Unescapes entities: `unescaped = html.unescape(clean_title)`.
       - Clamps title: `display_title = unescaped if len(unescaped) <= 55 else unescaped[:52] + "..."`.
       - Re-escapes title: `safe_title = html.escape(display_title)`.
       - Sanitizes URL: `raw_url = art.get("url", "#")`; ensures URL starts with `http://` or `https://`, else defaults to `#` (per T-05-05).
       - Escapes URL: `safe_url = html.escape(raw_url)`.
       - Escapes platform: `platform = html.escape(art.get("platform", "Article"))`.
       - Appends line: `* [{date}] <a href="{safe_url}">{safe_title}</a> ({platform})`.
     - Closes `</code></pre>\n</div>`.

   - `test_atom1_feed_parsing`: parses `feed_atom.xml`, asserts 1 article, link extracted from `href` attribute, date normalized to `2024-05-18`, and platform `"Workstation Research Notes"`.
   - `test_date_normalization`: verifies RFC 822 (`Sun, 19 May 2024 14:30:00 GMT`), ISO 8601 (`2024-05-18T08:00:00Z`), and plain `YYYY-MM-DD` inputs.
   - `test_title_clamping_and_escaping`: verifies title >55 chars is clamped with `...`, and HTML entities (`&amp;`, `&quot;`) are preserved safely.
   - `test_security_url_sanitization`: verifies `javascript:alert('xss')` is sanitized to `<a href="#">`.
   - `test_cache_ttl_and_refresh`: mocks `urllib.request.urlopen`, verifies cached entries within 12h avoid network calls, and `force_refresh=True` bypasses cache.
   - `test_network_fallbacks`: simulates `urllib.error.HTTPError(None, 404, "Not Found", None, None)` and verifies graceful fallback to curated articles.
   - `test_standby_formatting`: verifies `format_articles_terminal_log([])` outputs `* [standby] feed listener active`.
</action>
