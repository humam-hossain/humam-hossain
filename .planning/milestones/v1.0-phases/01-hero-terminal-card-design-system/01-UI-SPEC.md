- **Primary Visual Anchor:** Retro block-art `H_` monogram in Cyan (`#a5d6ff`) on the standalone left panel (~35% card width), anchored beneath by the 8-dot ANSI diagnostic strip (`<circle r="6">`).

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline text padding, icon-to-label gaps, badge inner padding |
| sm | 8px | Traffic light spacing (`cx="25, 45, 65"`), compact element margins, vertical gap between badge rows |
| md | 16px | Card corner radius buffer (`rx="10"` inset), traffic light margin from window edge (`cx="25"`), section vertical rhythm |
| lg | 24px | Monogram-to-telemetry column gap, vertical header bar offset, telemetry line height (`24px`) |

| 2xl | 48px | Outer profile section breaks, major container margin |
| 3xl | 64px | Page-level spacing, bottom buffer before exit sign-off |

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 | 1.5 |
| Label | 14px | 600 | 1.5 |
| Heading | 16px | 600 | 1.25 |
| Display | 20px | 600 | 1.1 |

- **Body**: 14px, weight 400, line height 1.5. Used for right-panel telemetry values (`.val`), contact handles, and standard profile copy.
- **Label**: 14px, weight 600, line height 1.5. Used for right-panel telemetry keys (`.key`), title bar text (`.title`), and status badges.
- **Heading**: 16px, weight 600, line height 1.25. Used for terminal telemetry prompt header (`humam@workstation:~`) and bottom exit sign-off.
- **Display**: 20px, weight 600, line height 1.1. Used for Neofetch retro block monogram `H_` ASCII art (`.mono-art`).

## UI Considerations

> Populated by the ui-phase UI-consideration probe (Step 9.5) and lifted by plan-phase's
> `## UI Considerations` lift rule via the identical rule as SPEC `## Edge Coverage`. Shape-rooted UI *state*
> coverage (empty / loading / error / populated / partial / overflow / zero-one-many / long-text).
> Empty-state and error-state COPY live in `## Copywriting Contract` above — this section covers
> state coverage and REFERENCES those rows rather than restating the copy (de-dup).

Applicable state considerations resolved: 6 covered, 0 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Dynamic telemetry values (`val-uptime`, `val-loc-add`, `val-loc-del`) | ✅ covered | In Phase 1 prior to API integration, telemetry renders documented static fallback strings (`4 yrs, 3 mos, 12 days` and `++320,410 / --85,240`) per CONTEXT.md D-09 |
| long-text | Telemetry values containing ampersands or long strings (`Kernel`, `Focus`) | ✅ covered | All string interpolations pass through `xml.sax.saxutils.escape()` escaping `&` to `&amp;`; text is bounded within x=310 to x=820 to prevent viewport overflow |
| overflow | SVG container scaling on narrow mobile viewports | ✅ covered | SVG uses responsive `viewBox="0 0 850 380"` embedded with `width="100%"` in README `<div align="center">`, ensuring fluid proportional downscaling without horizontal scrollbars down to 320px |
| error | Corrupted or missing token schema (`config/terminal_theme.json`) | ✅ covered | `scripts/generate_hero.py` validates token schema and raises actionable CLI error copy documented in Copywriting Contract; verified by `tests/test_tokens.py` |
| loading | GitHub Camo proxy image caching and font loading | ✅ covered | Hero card uses self-contained inline SVG styles and native system monospace fonts (`ui-monospace, SFMono-Regular, Menlo, Consolas`), eliminating external network requests and render latency |
| populated | Default profile hero display state | ✅ covered | Static SVG renders 8-line `H_` block monogram, 8 circular ANSI diagnostic dots, window traffic lights, and 8 telemetry rows with 100% XML parse validity |
