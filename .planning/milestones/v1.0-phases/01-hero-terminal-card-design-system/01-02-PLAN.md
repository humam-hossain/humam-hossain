# Plan 01-02: Python Hero SVG Generator & Production Terminal Vector Asset

## Executive Summary

Build the core visual component of Phase 1: the Python generator engine (`scripts/generate_hero.py`) and the production terminal hero vector asset (`assets/hero.svg`). Plan 01-02 implements Requirements HERO-01 (retro Neofetch `H_` block monogram with 8-dot ANSI strip) and HERO-02 (right-panel system telemetry with XML-escaped ampersands and Phase 2 DOM update hooks). The generator relies entirely on Python's standard library, prevents window header corner pixel bleed using an SVG `<clipPath>`, and guarantees 100% well-formed XML for GitHub Camo proxy delivery.

---

## Threat Model (ASVS Level 1)

<threat_model>
### STRIDE Threat Register

| Threat ID | Category | Component | Description | Mitigation Strategy |
|-----------|----------|-----------|-------------|---------------------|
| T-01-05 | Tampering | `scripts/generate_hero.py` | XML Injection: Raw unescaped ampersands (`&`) in telemetry (`AI & Robotics`, `Autonomous Systems, IoT & Cloud`) crash XML parsers and break Camo proxy rendering. | Mandatory `xml.sax.saxutils.escape()` applied to all telemetry values; `xml.etree.ElementTree.fromstring()` validation executed before writing output. |
| T-01-06 | Denial of Service | `assets/hero.svg` | SVG Malformation / Corrupted Markup: Malformed XML causes GitHub Camo proxy to return HTTP 500 or broken image badge. | Automated validation in `test_tokens.py` using `ET.fromstring(svg_content)` asserting root tag, viewBox, and DOM structure. |
| T-01-07 | Elevation of Privilege | `assets/hero.svg` | XSS / Camo Proxy Block: Script tags or inline event handlers (`onload`, `onclick`) trigger Camo sanitization stripping or security blocks. | Generator generates purely static SVG primitives (`<rect>`, `<text>`, `<tspan>`, `<circle>`, `<line>`); zero scripts or event handlers. |
| T-01-08 | Supply Chain (SC) | `scripts/generate_hero.py` | Compromised external templating libraries (e.g. Jinja2, Pillow). | Zero external dependencies; 100% Python standard library (`json`, `pathlib`, `xml.sax.saxutils`, `xml.etree.ElementTree`). |
</threat_model>

<action>
Create `scripts/generate_hero.py` implementing:
1. `generate_svg() -> str`:
   - Reads `config/terminal_theme.json` to extract `geometry`, `colors`, and `typography`.
   - Embeds scoped `<style>` block containing `.mono`, `.title`, `.mono-art`, `.prompt`, `.divider`, `.key`, `.val`, `.loc-add`, `.loc-del`.
   - Defines `<clipPath id="card-clip">` with `<rect width="850" height="380" rx="10" ry="10" />` to clip window background and header neatly without corner bleed.
   - Generates window chrome:
     - Header bar `#161b22` (height 38), 1px border line `#30363d`.
     - 3 macOS traffic light circles: Red (`#ff5f56`, cx=25), Yellow (`#ffbd2e`, cx=45), Green (`#27c93f`, cx=65) at cy=19, r=6.
     - Centered header title `humam@workstation:~` at x=425, y=24.
   - Left Panel (Hero Identity):
     - 8-line Neofetch `H_` block monogram with solid/half-block characters:
       `"▄▄     ▄▄"`
       `"██     ██"`
       `"██     ██"`
       `"█████████"`
       `"█████████"`
       `"██     ██"`
       `"██     ██"`
       `"▀▀     ▀▀  _"`
     - Rendered in cyan (`#a5d6ff`) with static cursor `_`, starting at x=60, y=82 with line height 22, `xml:space="preserve"`.
     - 8-dot ANSI diagnostic strip: `<circle cx="..." cy="295" r="6" fill="..." />` centered horizontally beneath monogram spanning x=62 to x=216 (`x_start=62`, `spacing=22`).
   - Right Panel (Telemetry):
     - Prompt header `humam@workstation:~` at x=310, y=82 in `#58a6ff`.
     - Dashed divider `-------------------` at x=310, y=105 in `#616e7f`.
     - 7 telemetry rows (`OS:`, `Host:`, `Kernel:`, `Focus:`, `Uptime:`, `Shell:`, `Contact:`) with Amber keys (`#ffa657`, padded 10 chars) and muted white values (`#c9d1d9`).
     - Escape all text values with `saxutils.escape()` (ensuring `AI & Robotics` becomes `AI &amp; Robotics`, `Autonomous Systems, IoT & Cloud` becomes `Autonomous Systems, IoT &amp; Cloud`).
     - Downstream DOM Hook: Uptime `<tspan id="val-uptime" class="val">4 yrs, 3 mos, 12 days</tspan>`.
     - Row 8: LOC metric with downstream DOM hooks:
       `<tspan class="key" xml:space="preserve">LOC:       </tspan><tspan id="val-loc-add" class="loc-add">++320,410</tspan><tspan class="val"> / </tspan><tspan id="val-loc-del" class="loc-del">--85,240</tspan>`.
   - Card outer border `<rect width="850" height="380" rx="10" ry="10" fill="none" stroke="#30363d" stroke-width="1" />`.
   - Validates generated XML string with `xml.etree.ElementTree.fromstring()` prior to return.
2. CLI entry point `if __name__ == "__main__":` writes output to `assets/hero.svg`.
</action>
