2. Define bot filter sets `BOT_AUTHORS` with `github-actions[bot]`, `dependabot[bot]`, `github-actions`, `dependabot`, and `FILTER_PREFIXES` tuple with `docs(update):`, `chore(deps):`, `bump `. Define `DEFAULT_ACTIVITY_FIXTURES` with a list of 3 event dictionaries for `linux_shell_scripting`, `Python`, and `nn` with keys `sha`, `repo`, `message`, `time_ago`, `url`, and `repo_url`.
3. Implement `compute_relative_time_str(dt: datetime.datetime, now_utc: datetime.datetime | None = None) -> str` in `scripts/update_profile.py`:
   - Calculates elapsed duration between `dt` and `now_utc`.
   - Returns human-friendly relative strings: "just now", "X hours ago", "1 day ago", "X days ago", "1 week ago", "X weeks ago", "X months ago".
4. Implement `format_git_activity_stream(activities: list[dict], now: datetime.datetime | None = None) -> str` in `scripts/update_profile.py` per D-13, D-14, D-15, D-16, D-18:
   - Filters out items where author matches `BOT_AUTHORS` or starts with `dependabot`/`github-actions`.
   - Filters out items whose message starts with any prefix in `FILTER_PREFIXES`.
   - Takes up to 6 events (`filtered[:6]`).
   - Clamps message headline to 50 characters: if `len(raw_msg) > 50`, `clamped = raw_msg[:47] + "..."` else `raw_msg` per D-16.
   - Escapes repo name with `html.escape(repo)` and message with `html.escape(clamped)`.
   - Assembles lines:
     - Header line: `<div align="left">\n<pre><code>humam@workstation:~$ git log --graph --oneline -n 6`
     - Event line: `* <a href="{commit_url}">[{sha}]</a> (<a href="{repo_url}">{escaped_repo}</a>) {escaped_msg} ({time_ago})`
     - Footer line: `</code></pre>\n</div>`
   - Returns assembled string joined with newlines.
5. Implement `fetch_recent_activity(cache: dict, token: str | None = None) -> list[dict]` in `scripts/update_profile.py` per D-17, D-22:
   - Tier 1: If `token` is present, queries GitHub Public Events `/users/humam-hossain/events/public` (or GraphQL repository commit history), parses push events and commits, computes relative times, updates `cache["recent_activity"]`, and returns parsed list.
   - Tier 2: On query error or token absence, checks `cache.get("recent_activity", {}).get("events")`; if present, returns cached events.
   - Tier 3: Falls back to `DEFAULT_ACTIVITY_FIXTURES`, logging `log_warn()`.
6. In `tests/test_metrics.py`, add unit tests:
   - `test_git_activity_formatting_output`: verifies prompt line, asterisks, and `<code>` wrapping.
   - `test_git_activity_message_clamping_50_chars`: asserts strings > 50 characters are clamped with `...`.
   - `test_bot_filtering_github_actions_and_dependabot`: asserts bot author commits are discarded.
   - `test_updater_commit_prefix_filtering`: asserts commits starting with `docs(update):` are discarded.
   - `test_html_escaping_in_commit_messages`: asserts `<` and `>` in commit messages are converted to `&lt;` and `&gt;`.
   - `test_relative_time_formatting`: verifies hours, days, and weeks relative time strings.
</action>
