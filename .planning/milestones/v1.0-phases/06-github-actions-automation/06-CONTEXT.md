# Phase 6: GitHub Actions Automation - Context

**Gathered:** 2026-11-15
**Status:** Ready for planning

<domain>
## Phase Boundary

Wire everything into a scheduled GitHub Actions workflow that runs the Python engine daily, commits updated SVGs and README, and costs $0. The workflow file `.github/workflows/profile-updater.yml` must support daily cron scheduling, manual dispatch with configuration inputs, and path-triggered push events — all using exclusively the standard `GITHUB_TOKEN` (with optional PAT fallback) and zero paid services.

</domain>

<decisions>
## Implementation Decisions

### Execution Schedule & Triggers
- **D-01:** Cron schedule set to `17 0 * * *` (00:17 UTC daily) to avoid top-of-hour GitHub Actions runner queue congestion — **Reversibility:** reversible
- **D-02:** Triple trigger configuration: `schedule` (daily cron) + `workflow_dispatch` (manual with `dry_run` boolean and `force_refresh` boolean inputs) + `push` on paths `scripts/**`, `config/**`, `templates/**`, `.github/workflows/profile-updater.yml` on branch `main` — **Reversibility:** reversible
- **D-03:** Concurrency group with `cancel-in-progress: false` — let in-flight profile updates finish cleanly to prevent corrupted git index or half-committed SVGs — **Reversibility:** reversible
- **D-04:** Single unified workflow file `.github/workflows/profile-updater.yml` with conditional commit step — PRs run update_profile.py in dry-run mode for validation only; commits only execute on schedule, workflow_dispatch, or main push — **Reversibility:** reversible
- **D-05:** Dual-layer recursive loop prevention: `[skip ci]` in commit message subject AND `paths-ignore` for generated files (`assets/*.svg`, `README.md`, `data/cache.json`) on push triggers — **Reversibility:** reversible
- **D-06:** `ubuntu-latest` runner with Python 3.12 via `actions/setup-python@v5` — no pip install step (Python stdlib only, zero external dependencies) — **Reversibility:** reversible
- **D-07:** Shallow checkout `fetch-depth: 1` via `actions/checkout@v4` with `lfs: false`, `submodules: false`, `persist-credentials: true` — **Reversibility:** reversible
- **D-08:** Dynamic run-name: `"Profile Telemetry Sync (${{ github.event_name }})"` for Actions UI clarity — **Reversibility:** reversible
- **D-09:** Repository-level execution (no named GitHub Environment required) — zero manual UI setup — **Reversibility:** reversible
- **D-10:** Job defaults: `defaults.run.shell: bash` for pipefail protection across all run steps — **Reversibility:** reversible
- **D-11:** Job `timeout-minutes: 10` (script normally finishes in <15s; prevents runaway runner usage) — **Reversibility:** reversible
- **D-12:** `PYTHONUNBUFFERED: "1"` environment variable and `python -u` for real-time terminal log streaming in CI — **Reversibility:** reversible
- **D-13:** Explicit least-privilege: `permissions: contents: write, pull-requests: read` with all other scopes disabled — **Reversibility:** reversible

### Git Commit & Bot Identity
- **D-14:** Committer identity: `github-actions[bot] <41898282+github-actions[bot]@users.noreply.github.com>` — canonical GitHub bot pairing with native web verification badge — **Reversibility:** reversible
- **D-15:** Identical Author and Committer fields (both `github-actions[bot]`) — uniform git metadata — **Reversibility:** reversible
- **D-16:** Commit message subject: `chore(profile): auto-sync terminal telemetry [skip ci]` — Conventional Commit format, ≤60 chars — **Reversibility:** reversible
- **D-17:** Multiline commit body with structured telemetry (uptime, LOC, streak) and machine-parseable Git Trailers (`Workflow-Run:`, `Workflow-Event:`) with 72-character line wrapping — **Reversibility:** reversible
- **D-18:** Commit message generated by `update_profile.py` writing `.git/COMMIT_MSG_TMP`; workflow executes `git commit --no-verify -F .git/COMMIT_MSG_TMP` then `rm -f .git/COMMIT_MSG_TMP` — eliminates shell escaping bugs — **Reversibility:** reversible
- **D-19:** Explicit staging target list: `git add assets/*.svg README.md data/cache.json` — strict staging boundaries — **Reversibility:** reversible
- **D-20:** File permission normalization: `chmod 644 assets/*.svg README.md data/cache.json` before staging — prevents file mode churn in git history — **Reversibility:** reversible
- **D-21:** Graceful no-op: check `git diff --cached --quiet`; if no visual asset changes (SVGs or README unchanged), exit 0 cleanly with `[INFO] No profile changes detected. Skipping commit.` — idempotent workflow runs — **Reversibility:** reversible
- **D-22:** Commit only when user-facing assets (`assets/*.svg` or `README.md`) have changed — `data/cache.json` alone does not trigger a commit — **Reversibility:** reversible
- **D-23:** Push resiliency: `git pull --rebase --autostash origin main` before `git push origin HEAD:main` with up to 3 retry attempts using progressive backoff (2s, 5s, 10s) — **Reversibility:** reversible
- **D-24:** Execute `git rebase --abort` on rebase conflict before retry — **Reversibility:** reversible
- **D-25:** Fail on push error after retries (`exit 1`) to trigger GitHub Actions failure notifications — **Reversibility:** reversible
- **D-26:** Git config scope: `git config --local` for user.name/email (repository-scoped, not global) — **Reversibility:** reversible
- **D-27:** Defensive `git config --global --add safe.directory "$GITHUB_WORKSPACE"` — prevents dubious ownership errors — **Reversibility:** reversible
- **D-28:** Unix LF line endings enforced: `git config --local core.autocrlf input` — **Reversibility:** reversible
- **D-29:** Audit check before commit: warn if unexpected untracked files exist, but leave them uncommitted — **Reversibility:** reversible
- **D-30:** Log `git status -s` and `git diff --stat` before committing for concise change summary in CI logs — **Reversibility:** reversible
- **D-31:** Terminal confirmation: `echo "[OK] Pushed commit $(git rev-parse --short HEAD) to origin/main"` — **Reversibility:** reversible
- **D-32:** Standard UTC timestamps (`TZ: UTC`) for all automated commits — **Reversibility:** reversible
- **D-33:** `LC_ALL=C.UTF-8` and `LANG=C.UTF-8` environment for bulletproof UTF-8 encoding — **Reversibility:** reversible
- **D-34:** Commit step guard: `if: success() && github.event_name != 'pull_request' && inputs.dry_run != true` — **Reversibility:** reversible
- **D-35:** Step UI name: `"🚀 Commit and push updated profile assets"` — **Reversibility:** reversible
- **D-36:** Native checkout credential persistence for git push authentication (no token in remote URLs) — **Reversibility:** reversible
- **D-37:** No Co-authored-by trailer — exclusive bot authorship — **Reversibility:** reversible
- **D-38:** Commits only (no git tags) — keeps tags and releases clean of daily telemetry — **Reversibility:** reversible
- **D-39:** Ephemeral runner teardown (no explicit git reset trap needed) — **Reversibility:** reversible
- **D-40:** Document branch protection ruleset bypass instructions in workflow comments for future reference — **Reversibility:** reversible

### Authentication & API Secrets
- **D-41:** Hybrid token hierarchy in workflow: `env: GITHUB_TOKEN: ${{ secrets.PROFILE_SECRET || secrets.GITHUB_TOKEN }}` — seamlessly uses optional PAT while defaulting to standard free token — **Reversibility:** reversible
- **D-42:** Export both `GITHUB_TOKEN` and `GH_TOKEN` in step environment for cross-tool compatibility — **Reversibility:** reversible
- **D-43:** Strict environment variable injection (`env:` block) — no token values in CLI arguments or process tables — **Reversibility:** reversible
- **D-44:** Token resolution priority in Python: `PROFILE_TOKEN` → `GITHUB_TOKEN` → `GH_TOKEN` → offline fallback — **Reversibility:** reversible
- **D-45:** Graceful read-only fallback for fork PRs: run validation with standard `GITHUB_TOKEN` and cache fallback — **Reversibility:** reversible
- **D-46:** Document minimum PAT scopes in workflow comments: fine-grained (`read:user`, `repo` for private contributions) and classic token equivalents — **Reversibility:** reversible
- **D-47:** Descriptive `User-Agent: "humam-workstation-updater/1.0 (+https://github.com/humam-hossain/humam-hossain)"` header on all GitHub API requests — **Reversibility:** reversible
- **D-48:** Explicit `X-GitHub-Api-Version: 2022-11-28` header on all API requests — **Reversibility:** reversible
- **D-49:** Automatic fallback on HTTP 401: log warning and downgrade to default `GITHUB_TOKEN` if custom PAT expires — **Reversibility:** reversible
- **D-50:** Respect Retry-After on HTTP 403 (if ≤30s); otherwise fall back to `data/cache.json` with warning — **Reversibility:** reversible
- **D-51:** Granular GraphQL error handling: parse `errors[]` array; if `RATE_LIMITED` or `FORBIDDEN`, log warning and use cache fallback; log query errors with error type — **Reversibility:** reversible
- **D-52:** Configurable GraphQL endpoint: `os.environ.get("GITHUB_GRAPHQL_URL", "https://api.github.com/graphql")` — **Reversibility:** reversible
- **D-53:** Log remaining GraphQL rate limit quota: `[INFO] GitHub GraphQL rate limit: 995/1000 remaining` — **Reversibility:** reversible
- **D-54:** 15-second network timeout with up to 2 retries on GraphQL API requests — **Reversibility:** reversible
- **D-55:** Offline local execution: exit 0 with `[WARN] No token found. Running offline with cached/mock telemetry` — **Reversibility:** reversible
- **D-56:** Native GitHub runner secret masking (no redundant `::add-mask::` needed) — **Reversibility:** reversible

### Failure Handling & Workflow Telemetry
- **D-57:** Strict hard-fail on generation errors (Python crash, XML malformation, README marker corruption) → `exit 1`; soft-fail with cache fallback on external network/API timeouts → `exit 0` with warnings — **Reversibility:** reversible
- **D-58:** Pre-commit SVG integrity gate: validate all SVGs parse with `xml.etree.ElementTree` and exceed 500 bytes minimum — **Reversibility:** reversible
- **D-59:** Pre-commit README marker gate: verify all `<!-- *:START -->` / `<!-- *:END -->` section marker pairs exist — **Reversibility:** reversible
- **D-60:** Upload debug artifacts on failure (`if: failure()`) with `actions/upload-artifact@v4` and 7-day retention — packages logs, invalid SVGs, and cache.json — **Reversibility:** reversible
- **D-61:** Rich terminal-themed `$GITHUB_STEP_SUMMARY`: Neofetch prompt header in ````ansi` codeblock (top), then Markdown asset verification table with byte sizes and XML validity badges (bottom) — **Reversibility:** reversible
- **D-62:** Failure diagnostic banner in `$GITHUB_STEP_SUMMARY`: red alert block with failed step name and remediation advice — **Reversibility:** reversible
- **D-63:** Script execution duration tracked and displayed in Step Summary — **Reversibility:** reversible
- **D-64:** ANSI terminal colored logging (Green `[OK]`, Amber `[WARN]`, Red `[FAIL]`, Cyan `[INFO]`) in GitHub Actions live runner console — **Reversibility:** reversible
- **D-65:** Native GitHub alerts only (email + Actions tab) for failure notifications — zero external webhooks — **Reversibility:** reversible
- **D-66:** Dry-run mode: full write + validate on disk, skip git commit — proves everything works before discarding runner — **Reversibility:** reversible
- **D-67:** Auto-enable `--verbose` mode when `runner.debug` is `"1"` — hooks into GitHub's "Re-run with debug logging" button — **Reversibility:** reversible
- **D-68:** 3 HTTP retries with exponential backoff (1s, 2s, 4s) for 5xx/connection errors before cache fallback — **Reversibility:** reversible
- **D-69:** Auto-recovery from corrupt `data/cache.json`: log warning, initialize clean baseline structure, continue — **Reversibility:** reversible
- **D-70:** Standard Unix exit codes: 0 (success or graceful fallback), 1 (fatal invariant failure) — **Reversibility:** reversible
- **D-71:** Multi-layer pre-deployment local validation: YAML schema check + `update_profile.py --dry-run` + SVG ElementTree verification — **Reversibility:** reversible
- **D-72:** Exclude workflow status badge from README.md to preserve strict terminal aesthetic — **Reversibility:** reversible

### Runner Performance, Quota & Budget
- **D-84:** Zero third-party marketplace actions — strictly official GitHub-maintained actions only (`actions/checkout@v4`, `actions/setup-python@v5`, `actions/upload-artifact@v4`) — **Reversibility:** one-way — switching to third-party actions later changes the security trust model and supply chain
- **D-85:** Performance budget: <30s typical execution, ≤45s cap (~15 min compute/month across 30 daily runs) — **Reversibility:** reversible
- **D-86:** $0 infrastructure cost verification: GitHub provides unlimited free runner minutes for public repositories — formally documented — **Reversibility:** reversible
- **D-87:** Pin actions to official major versions (`@v4`, `@v5`) — auto-receive patch/security fixes — **Reversibility:** reversible

### Security Hardening & Injection Prevention
- **D-88:** Enforce intermediate environment variables for all GitHub context expressions (`env: EVENT_NAME: ${{ github.event_name }}`) — prevents bash script injection — **Reversibility:** one-way — removing this protection creates a security regression
- **D-89:** Dual-layer branch assertion: YAML `if` condition AND bash assertion `[ "$GITHUB_REF" = "refs/heads/main" ]` before push — **Reversibility:** reversible
- **D-90:** Strict `subprocess.run(['git', ...], shell=False)` in Python — no shell injection risk — **Reversibility:** reversible

### 60-Day Inactivity Keep-Alive
- **D-91:** Natural heartbeat: daily coding uptime increment in `hero.svg` produces a visual diff and commit every 24h, permanently resetting GitHub's 60-day inactivity clock — **Reversibility:** reversible
- **D-92:** Document manual workflow re-enable instructions (`gh workflow enable` or GitHub UI) in workflow comments — **Reversibility:** reversible
- **D-93:** Neofetch uptime + recent git log activity as authentic visual proof of live automation health — **Reversibility:** reversible
- **D-94:** Accept standard GitHub Actions cron jitter (15-30m latency window) — satisfies 24h freshness guarantee — **Reversibility:** reversible

### Cross-Platform Developer Parity
- **D-95:** Universal `pathlib.Path` for all file operations and `sys.executable` for subprocess Python calls — cross-platform compatibility — **Reversibility:** reversible
- **D-96:** Auto-enable VT100 ANSI on Windows with graceful plain-text fallback for legacy `cmd.exe` — **Reversibility:** reversible
- **D-97:** POSIX-compatible bash (`#!/usr/bin/env bash` without GNU-specific flags) for `tests/test_ci_pipeline.sh` — runs on macOS, Linux, and Windows Git Bash — **Reversibility:** reversible
- **D-98:** Repository-level `.gitattributes` enforcing LF line endings: `*.svg`, `*.py`, `*.json`, `*.md text eol=lf` — **Reversibility:** reversible

### Repository Size & Git History
- **D-99:** Plain text git storage for SVGs (no Git LFS) — text diffs compress efficiently via zlib delta (<5 MB/year in packfiles) — **Reversibility:** costly — migrating to Git LFS retroactively requires rewriting history
- **D-100:** Permanent commit history retention (no squashing) — maintains genuine audit trails — **Reversibility:** costly — squashing later loses granular daily commit references
- **D-101:** Comprehensive `.gitignore` hygiene: `__pycache__`, `*.pyc`, `.venv`, `*.tmp`, `.pytest_cache` — **Reversibility:** reversible
- **D-102:** Zero manual git maintenance — rely on GitHub's native cloud backend `git gc` — **Reversibility:** reversible
