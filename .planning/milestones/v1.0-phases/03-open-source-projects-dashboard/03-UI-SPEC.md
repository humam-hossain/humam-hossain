## Color

Adheres strictly to the 60/30/10 dark terminal color architecture:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0d1117` | Terminal console canvas, root SVG background, profile dark surface |
| Secondary (30%) | `#161b22` | Window header bar, 4 project sub-panel card backgrounds, 1px border (`#30363d`) |
| Accent (10%) | `#a5d6ff` | High-contrast Cyan reserved exclusively for repository titles and CLI directory segments |
| Destructive | `#f85149` | macOS Close traffic light (`#ff5f56`) and terminal error warning alerts |

Accent reserved for:
- Repository titles (`.repo-title`) in project sub-panels
- Active directory segment (`~/projects$`) in the terminal prompt line
- Clickable repository links in the README.md terminal quick-links line (`<code>humam@workstation:~/projects$ cd <a href="...">repo</a></code>`)

Semantic Metric Color Indicators (secondary telemetry accents):
- Star Yellow: `#f1e05a` (Star count indicator)
- Fork Blue: `#58a6ff` (Fork count indicator)
- Issue Amber: `#ffa657` (Open issue count indicator)
- PR Purple: `#a371f7` (Open pull request count indicator)
- Inactive/Zero Count Muted Gray: `#616e7f` (Metric icons and counters evaluated to 0)
- Body / Description Muted: `#8b949e` (2-line clamped repository descriptions)
- Value Foreground: `#c9d1d9` (CLI command arguments and card metadata)

## Visuals & Hierarchy

- **Primary Screen Focal Point:** The 2x2 grid of project sub-panels in `assets/projects.svg`, specifically the Cyan repository titles (`#a5d6ff`) in the top row.
- **Visual Hierarchy:**
  1. Window Chrome: Workstation title bar (`projects — zsh`) with macOS traffic lights (`#ff5f56`, `#ffbd2e`, `#27c93f`) establishing the Unix desktop frame.
  2. CLI Prompt: `humam@workstation:~/projects$ gh repo list` at `y=62` providing command-line narrative.
  3. Canvas Grid: 2-column by 2-row grid of sub-panel cards (`#161b22`, border `#30363d`, `rx=6`) against `#0d1117`.
  4. Card Header: Cyan repository title (`📁 repo-name`) on the left opposite language indicator (`● Python`) on the right.
  5. Card Body: 2-line clamped repository description in muted gray (`#8b949e`) with ellipsis (`...`) truncation at 85 characters.
  6. Card Baseline: Real-time metric strip (`★ Stars`, `⌥ Forks`, `⊙ Issues`, `⑂ PRs`) with vibrant ANSI values for non-zero counts and muted `#616e7f` for zeros.
  7. Section Footer: Authentically formatted markdown command line in `README.md` providing direct clickable repository links.
- **Accessibility & Label Fallbacks:**
  - All SVG metric icons provide accessible `<title>` elements and formatted labels (e.g., `★ 14 stars`).
  - Terminal quick-links in `README.md` supply accessible text hyperlinks (`<a href="https://github.com/humam-hossain/repo">repo</a>`).

## UI Considerations

> Populated by the ui-phase UI-consideration probe (Step 9.5) and lifted by plan-phase's
> `## UI Considerations` lift rule via the identical rule as SPEC `## Edge Coverage`. Shape-rooted UI *state*
> coverage (empty / loading / error / populated / partial / overflow / zero-one-many / long-text).
> Empty-state and error-state COPY live in `## Copywriting Contract` above — this section covers
> state coverage and REFERENCES those rows rather than restating the copy (de-dup).

Applicable state considerations resolved: 8 covered, 0 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Curated projects list (`config/projects.json`) | ✅ covered | When `config/projects.json` is missing or contains 0 repositories, the dashboard renders the empty-state sub-panel defined in Copywriting Contract above. |
| loading | SVG rendering and font assets | ✅ covered | Pre-rendered static SVG during CI/local update run; GitHub serves via Camo proxy with zero client-side async fetch spinner or latency. System monospace font stack ensures instant layout. |
| error | GraphQL API failure or missing token | ✅ covered | `scripts/update_profile.py` intercepts network errors and falls back to cached snapshot in `data/cache.json` with warning log per Copywriting Contract. |
| populated | 2x2 grid featured projects showcase | ✅ covered | Normal state displays 4 curated repositories with Cyan titles (`#a5d6ff`), language dot indicator, 2-line clamped description (`#8b949e`), and ANSI metric counter row. |
| partial | Fewer than 4 repositories declared or missing description | ✅ covered | If fewer than 4 repositories are pinned, empty slots render clean placeholder dashed borders or collapse; missing descriptions fallback to GitHub topics or default summary per CONTEXT.md D-14. |
| overflow | Descriptions and mobile viewport scaling | ✅ covered | Repository descriptions are clamped strictly to 2 lines (~80–85 characters) with ellipsis truncation per CONTEXT.md D-13; SVG uses responsive `viewBox="0 0 850 340"` with `width="100%"` in README to prevent horizontal scrollbars on mobile. |
| zero-one-many | Real-time metric counters | ✅ covered | Metric counters format raw integer values cleanly (`★ 14`, `⌥ 2`, `⊙ 0`); zero counts are rendered in muted gray (`#616e7f`) per CONTEXT.md D-12 to preserve layout stability without visual noise. |
| long-text | Repository titles and XML entity escaping | ✅ covered | Long repository names truncated or scaled to fit 380px sub-panel width; all string interpolations are XML-escaped via `xml.sax.saxutils.escape()`. |
