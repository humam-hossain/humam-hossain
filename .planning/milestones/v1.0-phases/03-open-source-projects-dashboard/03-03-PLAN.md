# Plan 03-03: Coordinator Pipeline, Cache Persistence & Surgical README Injection

## Executive Summary

Integrate all Open Source Projects Dashboard components into the primary profile automation engine (`scripts/update_profile.py`), wire cache persistence into `data/cache.json`, and perform surgical idempotent injection into `README.md`. Plan 03-03 connects the curated config loader and batched GraphQL query engine from Plan 03-01 with the standalone SVG generator from Plan 03-02 per D-15. It persists fetched repository telemetry under `project_metrics` in `data/cache.json` alongside a UTC ISO-8601 timestamp per D-17. It implements `update_readme_projects()` to inject `assets/projects.svg` and interactive terminal command quick-links (`<code>humam@workstation:~/projects$ cd <a href="...">repo</a></code>`) directly between `<!-- PROJECTS:START -->` and `<!-- PROJECTS:END -->` per D-04 and D-05. Strict byte-equality checks ensure idempotent writes per D-19. End-to-end integration tests in `tests/test_projects.py` verify full offline execution and complete regression health across the repository.

### STRIDE Threat Register

| Threat ID | Category | Component | Description | Mitigation Strategy |
|-----------|----------|-----------|-------------|---------------------|
| T-03-11 | Tampering / File Corruption | `scripts/update_profile.py:update_readme_projects` | Corrupting or wiping existing `README.md` content (e.g. hero card, contact badges, exit prompt) during anchor replacement. | Search for exact substring boundaries `start_idx = content.index("<!-- PROJECTS:START -->") + len(...)` and `end_idx = content.index("<!-- PROJECTS:END -->")`. | T-03-12 | Denial of Service / Git Churn | `scripts/update_profile.py:update_readme_projects` | Frequent empty git commits triggered by non-idempotent README or SVG writes during automated daily GitHub Actions runs. | Compare candidate string against existing file content before writing (`if new_content == content: return False`). Log `[INFO] ... already up to date (idempotent skip)` per D-19. |
| T-03-13 | Data Loss / Cache Corruption | `scripts/update_profile.py:main` | Wiping Phase 2 telemetry cache keys (`baseline`, `repositories`, `totals`) when saving `project_metrics`. | Pass shared `cache` dictionary throughout `main()`; update `cache["project_metrics"]` in-place; write back using `save_cache(CACHE_PATH, cache)`. |
| T-03-14 | Injection / Malicious URLs | `scripts/update_profile.py:update_readme_projects` | URL injection or markdown escaping issues in README quick-links (`<a href="...">`). | Validate URL targets begin with `https://github.com/`; escape display names and URLs before template interpolation. |
| T-03-15 | Elevation of Privilege | File System Permissions | Accidental modification of files outside the repository working tree. | Constrain all file path resolutions to `ROOT_DIR` (`ROOT_DIR / "assets" / "projects.svg"`, `ROOT_DIR / "README.md"`, `ROOT_DIR / "data" / "cache.json"`). |

- `update_readme_projects()`:
  - Locates `<!-- PROJECTS:START -->` and `<!-- PROJECTS:END -->`.
  - Builds clickable markdown command links: `cd <a href="{url}">{name}</a>` joined by ` | `.
  - Injects centered `assets/projects.svg` image tag followed by centered `<code>humam@workstation:~/projects$ {links}</code>`.
  - Performs byte comparison: if content is identical, skips write and returns `False` (idempotent skip per D-19).
  - If content changed, writes file and returns `True`.
  - If anchors are missing, logs `[WARN]` and returns `False` without altering the file.
- `scripts/update_profile.py:main()` calls `update_readme_projects(README_PATH, projects_data)`.
- Running `python3 scripts/update_profile.py` injects projects dashboard into `README.md` between markers.
- Subsequent run returns `False` for README update and prints `[INFO] README.md projects section already up to date (idempotent skip)`.
- Surrounding content in `README.md` (Hero card, contact badges, exit prompt) remains intact.
</acceptance_criteria>

<action>
1. In `scripts/update_profile.py`, define `README_PATH = ROOT_DIR / "README.md"`.
2. Implement `update_readme_projects(readme_path: Path, projects: list[dict]) -> bool` per D-04, D-05, D-19:
   - Check if `readme_path.is_file()`; if not, log `[WARN]` and return `False`.
   - Read content with UTF-8 encoding.
   - Verify `"<!-- PROJECTS:START -->"` and `"<!-- PROJECTS:END -->"` are present; if missing, log `[WARN]` and return `False`.
   - Calculate `start_idx = content.index("<!-- PROJECTS:START -->") + len("<!-- PROJECTS:START -->")` and `end_idx = content.index("<!-- PROJECTS:END -->")`.
   - Build links for up to 4 projects:
     ```python
     links = []
     for p in projects[:4]:
         name = p.get("name") or p.get("repo", "").split("/")[-1]
         url = p.get("url") or f"https://github.com/{p.get('repo')}"
         links.append(f'cd <a href="{url}">{name}</a>')
     links_cmd = " | ".join(links)
     ```
   - Format replacement block:
     ```python
     replacement = f"""
     <div align="center">
       <img src="./assets/projects.svg" alt="Open Source Projects Dashboard" width="100%" />
     </div>

     <div align="center">
       <code>humam@workstation:~/projects$ {links_cmd}</code>
     </div>
     """
     ```
   - Assemble `new_content = content[:start_idx] + "\n" + replacement.strip() + "\n" + content[end_idx:]`.
   - If `new_content == content`: log `[INFO] README.md projects section already up to date (idempotent skip)` and return `False`.
   - Write `new_content` to `readme_path`; log `[OK] Updated README.md with projects dashboard` and return `True`.
3. In `scripts/update_profile.py:main()`, call `update_readme_projects(README_PATH, projects_data)` right after `write_svg_idempotent()`.
4. Run `python3 scripts/update_profile.py` to perform the initial update on `README.md`.
</action>
