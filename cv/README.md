# CV Maker Using LaTeX

Install TeX Live packages as needed for your OS, then build:

```bash
# general CV (default)
./build.sh

# staff-aug / SQA-oriented variant (Linux, testing, Git, VPS)
./build.sh cv_humam_hossain_sqa
```

Outputs: `cv_humam_hossain.pdf` or `cv_humam_hossain_sqa.pdf` in this directory.
